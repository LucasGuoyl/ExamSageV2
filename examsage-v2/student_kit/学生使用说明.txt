押题宝学生包 · Windows 本地试点

直接在押题宝里学习
1. 在 Windows 上用你自己的 ChatGPT 账号登录官方 Codex 桌面应用。电脑须已有该应用随附的 Python 运行时（含 Tk、Pydantic v2、pypdf、Pillow 和 pypdfium2）。
2. 把下载的 ZIP 全部解压到你自己的文件夹，然后双击“开始学习.bat”。第一次在窗口中点“导入课件”，选择 PDF、PPTX、TXT 或 MD，填写课程名、学科和资料类别。原来用押题宝学生包导入的个人课程也会出现。
想先体验时，点“试用弹簧课件”。窗口会打开包内原始的两页 lesson.txt。先问“原题给的刚度和拉力是多少？求伸长量，注明条件和推导各在哪一页。”再在同一个对话追问“如果把拉力改成 20 N 呢？”
3. 在底部输入课程问题，按 Ctrl + Enter 或点击向上箭头发送；按 Enter 换行。回答生成时可点击停止。追问直接在同一输入框输入。点回答署名旁的“本题出处总览”，可看整道题实际引用了哪些考卷、讲义，以及各自对应哪些要点。点某段的“对照出处”，分别查看该段的引用和同知识点的关联线索。真题卡显示已核实的题号、登记考年与文件物理页码。点卡片或正文页码打开原页，再点“返回出处对照”。真题页和讲义页可分别查看。只有讲义时，真题栏会说明当前的查找结果。PDF 和已有原图的 PPTX 可切换到原图并放大。窄屏点页码展开阅读，点右上角关闭返回对话。Alt + R 打开原文，Alt + Q 回到输入框。左栏可切换课程、打开已有对话或新建对话。回答署名旁的“ChatGPT 套餐”表示本轮已通过套餐检查。窗口由本机浏览器打开。重新打开时使用学生包内同一个“开始学习.bat”。
想把这一页留到下次练习，打开引用原页，点“加入本课复习”。从左侧“本课复习”选择页面，先回忆或写下自己的答案，再点“揭开原页核对”。可以为下次改写问题，选“还要练”或“已掌握这页”。练习草稿只在本次卡片中显示，问题和自评保存在这台电脑的本课程中。
4. 课程和学习窗口的对话记录保存在当前 Windows 用户的 LocalAppData/ExamSage/student-workspaces 下。提交问题会通过官方 Codex 把问题、对话上下文和检索所需的课程片段交给 ChatGPT。套餐额度由账号管理；登录不是 ChatGPT、额度不足或普通套餐用量无法确认时，窗口会提示并停止。支持范围取决于账号和已安装的官方运行时。

第一次从 GitHub 下载时，选择发布附件 ExamSage-Study-Windows.zip。日常学习只需“开始学习.bat”。下面是希望在 Codex 原生对话里使用课程工具时的单独安装步骤。

可选：安装桌面插件
1. 在 Windows Codex 桌面应用登录你现有的 ChatGPT 账户。该机器需已有 Codex 随附的 Python 运行时，包含 Pydantic v2、pypdf、Pillow、pypdfium2 和 Tk。用浏览器打开普通 ChatGPT 的试点另行验证。
2. 将整个 ZIP 解压到你自己的可写目录并保留它。双击“1-登记学生插件.bat”。它用本机运行时准备原创四科演示和个人课程插件，然后将“押题宝学生版”加入你的 Codex 插件目录。
3. 在 Codex 插件目录选择“押题宝学生版”，安装并启用“押题宝 · 我的课程”和“押题宝 · 四科演示”。若当前对话还没出现工具，完全退出再打开 Codex。模型由桌面应用和当前套餐提供。
4. 双击“2-导入自己的课件.bat”，一次选择同一门课的 PDF、PPTX、TXT 或 MD 文件（最多 24 份，合计 64 MiB）。填写课程名、学科和资料类别。模拟试卷可单独选“模拟卷”。标明往年真题、答案和模拟卷的年份；未知可留空。资料保存在本机当前 Windows 用户的 LocalAppData 下的 ExamSage/student-workspaces。共用同一个 Windows 登录的人也共用这个学生空间。

可以直接问
“在我的课程中，刚导入的课程有哪些？找出课件关于某个概念的原话，给出文件名和页码。”
“请按过去几年的正式试卷，给出明年复习顺序。哪些年份有依据？有多少道题无法归类？请各举一题并注明原卷页码。”
“在物理演示中，弹簧刚度为 200 N/m，拉力改为 20 N 时伸长多少？沿用上题条件，指出各条件来自哪一页。”
“历史演示中，宣言的原文能支持哪条主张？还要哪些史料才能判断当时的实际情况？”

没有主题标题的真题
可以问“根据 2025 年以前的正式卷，逐小问整理地下水考点。给出能查回的题号和原句，说明哪些判断需要老师核对。”助手先按编号浏览往卷，再提交候选归类核对。每项列出年份、文件、题号、页码和短引。归类仍需你或任课教师判断；两份试卷里的相似题型也可能考不同技能。本次候选保留在对话里。

图片、答案与考试范围
PDF 可以请求原页图片。PPTX 的页面文字、内置图片和整页渲染是不同能力；请以来源工具返回的可用状态为准。导入后语义审核初始为待核查。历年题目支持整理有据可查的复习重点；题目与答案的配对、学校官方身份及下一年考什么，都需要相应证据。演示资料是教学样例。

维护
将 ZIP 分发到另一台电脑时，在接收方重新执行第一步登记命令。已生成的 marketplace 目录记录了接收方的解释器位置，请保留该目录。个人资料可以跨本机插件重装保留；请妥善备份自己的 Windows 数据。若运行时缺失或同名目录指向别处，窗口会提示原因。线上账号隔离和云端访问等待独立试点。

学生插件 0.6.4 支持卷面明确标记的中英文主题。已导入的课程仍按当前 Windows 用户读取。对照不同试点版本时，在 Codex 核对插件版本为 0.6.4。已登记过旧版学生试点的用户，先在 Codex 插件页卸载旧的两个学生插件，再用 Codex CLI 移除旧学生目录登记（codex plugin marketplace remove examsage-student）。将新版解压到新的可写目录，按上文登记、安装并启用。个人课件位于 LocalAppData 下，可在新版直接读取。
